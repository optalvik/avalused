# Arvutivõrkude alused

**Õppematerjalid arvutivõrkude põhialustest — OSI mudelist Cisco seadmete seadistamiseni.**

## Kursuse info

- **Maht:** ~32 akadeemilist tundi
- **Sihtrühm:** IT-süsteemide nooremspetsialisti eriala (tase 4) õppijad
- **Seos õppekavaga:** Arvutivõrgud (16 EKAP)
- **Ettevalmistus:** CCNA 200-301
- **Litsents:** CC BY-SA 4.0
- **Autor:** Maria Talvik

## Sisu

Kursus koosneb 16 teooriaosast ja 11 praktikumist.

**Teooria:**

| # | Teema | Kirjeldus |
|---|-------|-----------|
| 00 | Sissejuhatus | Arvutivõrkude ajalugu, eesmärk ja põhimõisted |
| 00a | Võrguseadmed | Ruuterid, kommutaatorid, sillad, jaoturid |
| 00b | Topoloogiad | Täht, siin, rõngas, võrk |
| 00c | Võrgutüübid | LAN, WAN, MAN, PAN ja Eesti infrastruktuur |
| 01 | Protokollid ja mudelid | OSI ja TCP/IP mudelid, kapseldamine |
| 02 | Füüsiline kiht | Kaablid, signaalid, konnektorid, standardid |
| 03 | Juhtmevabad võrgud | WiFi, Bluetooth, 5G, turvaprobleemid |
| 04 | Andmesidekiht | Ethernet, MAC-aadressid, kommutaatori töö |
| 05 | ARP | Address Resolution Protocol — IP → MAC |
| 06 | Võrgukiht | IP-aadressid, ruutimine, default gateway |
| 07 | Transpordikiht | TCP vs UDP, pordid, kolmekäiguline kätlus |
| 08 | IPv4 adresseerimine | Aadressiklassid, avalikud ja privaatsed aadressid |
| 09 | Kahendsüsteem | Kahend- ja kümnendsüsteemi teisendamine |
| 10 | Alamvõrgustamine | Alamvõrgumask, CIDR, võrgu- ja leviedastusaadress |
| 11 | VLSM | Muutuva pikkusega alamvõrgumaskid |
| 12 | Marsruutimine | Staatiline ja dünaamiline marsruutimine |
| 13 | DHCP ja DNS | Automaatne adresseerimine ja nimelahendus |
| 14 | Tõrkeotsing | Süstemaatiline tõrkeotsing, tööriistad |

**Praktikumid:**

| # | Teema | Mida õpid |
|---|-------|-----------|
| 01 | Packet Tracer ja esimene võrk | Installeerimine, lihtne võrk, ping |
| 02 | CLI ja kommutaatori seadistamine | IOS režiimid, paroolid, haldusaadress |
| 03 | Kommutaatori ja ruuteri seadistamine | LAN ruuteri ja kommutaatoriga |
| 04 | Ruuteri seadistamine ja DHCP | Kahe alamvõrguga topoloogia, DHCP relay |
| 05 | Ethernet-kaabli valmistamine | Cat5e, T-568B, RJ-45, testimine |
| 06 | MAC-aadresside tabel | Kommutaatori MAC-tabel, Simulation mode |
| 07 | Ruuteri avastamine ja seadistamine | Ruuteri riistvara, liidesed, marsruutimistabel |
| 08 | Staatiline marsruutimine | Staatilised marsruudid kahe ruuteri vahel |
| 09 | Staatiline marsruutimine (iseseisev) | Iseseisev harjutus |
| 10 | Dünaamiline marsruutimine | RIP, OSPF, EIGRP |
| 11 | DHCP ja DNS | Ruuter DHCP serverina, DNS-kirjed |
